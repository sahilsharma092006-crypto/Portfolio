# Portfolio

This is a personal portfolio website designed to showcase my projects and skills.

## Tech Stack
- **Frontend:** Next.js (App Router)
- **AI Integration:** Genkit JS with Gemini 2.5 Flash
- **Backend:** Firebase (Firestore, App Hosting)
- **Styling:** Tailwind CSS / 3D Components

## Getting Started
1. Install dependencies: `npm install`
2. Set environment variable: `export GEMINI_API_KEY=your_key`
3. Start Genkit UI: `npm run genkit:ui`
4. Local development: `npm run dev`
5. Deploy: `firebase deploy`
